# 메이플랜드 버프 알람

버프(스킬 / 소환수 / 소모품) 지속시간을 추적해서 끊기기 전에 **음성과 오버레이로** 알려주는
Windows 데스크톱 앱입니다.

설계 배경과 결정 근거는 [`DESIGN.md`](DESIGN.md) 에 있습니다.

---

## 이 앱이 하지 않는 것

**게임에 키 입력을 넣지 않습니다.** 자동 재버프는 매크로에 해당하며 제재 대상이라
구현되어 있지 않고, 앞으로도 넣지 않습니다.

이 앱이 하는 일은 키 입력을 **읽고**, 화면에 창을 **띄우고**, 소리를 **내는** 것까지입니다.
게임 프로세스에 어떤 것도 쓰지 않습니다.

---

## 실행

```bash
npm install
npm start
```

> ⚠️ **`git pull` 후에는 `npm install` 을 한 번 더 실행하세요.**
> 새 의존성이 추가됐는데 설치하지 않으면
> `Cannot find module 'uiohook-napi'` 같은 오류가 납니다.

Windows 실행 파일(설치 없이 쓰는 portable exe)을 만들려면:

```bash
npm run dist
```

### 빌드 도구는 필요 없습니다

키 후킹에 쓰는 `uiohook-napi` 는 **컴파일된 Windows 바이너리를 패키지에 담아서** 배포합니다.
Visual Studio 나 Python 같은 빌드 도구를 따로 깔 필요가 없고, `npm install` 만 하면 됩니다.

## 테스트

```bash
npm test                   # 타이머 코어 · 단축키 해석 · 발화 문구 (순수 node)
npm run test:integration   # 저장소 · 알림 정책 · 후킹 배선 (Electron 필요)
```

## 쓰는 법

### 1. 캐릭터 등록

**캐릭터 탭**에서 `+ 새 캐릭터`. 버프 목록은 캐릭터마다 따로 저장됩니다.
직업이 아니라 캐릭터 단위인 이유는, 같은 직업이어도 스킬 레벨에 따라 지속시간이 다르기 때문입니다.

비슷한 캐릭터를 추가할 때는 **복제**가 빠릅니다. 버프 목록을 통째로 물려받으므로
지속시간만 고치면 됩니다.

### 2. 버프 입력

**버프 탭**에서 `+ 버프 추가` 후 직접 입력합니다.

| 칸 | 설명 |
|---|---|
| 버프 이름 | 자유 입력. 다른 캐릭터에 이미 쓴 이름은 자동완성으로 제안됩니다 |
| 지속시간(초) | **게임 스킬창의 실제 값**을 보고 입력하세요 |
| 사전알림(초) | 만료 몇 초 전에 알릴지. 기본 10초 |
| 소환수 | 맵 이동·사망 시 사라지는 버프 (이프리트 등). `소환수 리셋` 대상이 됩니다 |
| 사용 | 끄면 오버레이와 타이머에서 빠집니다 |

앱은 기본 버프 목록을 동봉하지 않습니다. 버프의 정체를 모르고, 알 필요도 없습니다 —
**이름 + 지속시간**이 전부라서 밸런스 패치로 지속시간이 바뀌어도 앱 업데이트가 필요 없습니다.

### 3. 단축키 등록

설정 탭에서 **"게임에서 스킬 키를 누르면 타이머를 자동으로 시작"** 을 켠 뒤,
버프 탭의 각 줄에서 **등록** 버튼을 누르고 **실제로 그 키를 누르면** 됩니다 (Esc = 취소).

문자열로 타이핑하지 않고 실제 키를 캡처하므로, `Ins`/`PgUp` 같은 키나
**상단 숫자열 vs 넘패드**, **좌/우 Shift** 를 신경 쓸 필요가 없습니다.
`Shift` `Ctrl` `Alt` 를 **단독으로** 스킬 키에 배치했어도 그대로 등록됩니다.

캐릭터 탭에서는 **전환 단축키**를 등록할 수 있습니다. 게임 중 캐릭터를 바꿀 때
Alt+Tab 없이 그 키만 누르면 해당 캐릭터의 버프 세트로 전환됩니다.

설정 탭 아래쪽에서 **앱 단축키**(전체 리셋 / 소환수 리셋 / 음소거 / 오버레이 토글)도 등록합니다.
기본값은 일부러 비워 뒀습니다 — 게임에서 거의 모든 키를 쓰기 때문에 미리 정해둔 조합은
높은 확률로 충돌합니다.

같은 키에 두 개 이상이 걸리면 버프 탭 위에 **경고 배너**가 뜹니다. 하나는 반드시 안 먹습니다.

> **키를 읽기만 합니다.** 등록한 키는 게임으로 그대로 전달됩니다 — 앱이 가로채지 않습니다.
> Electron의 `globalShortcut`을 쓰면 그 키가 게임에 안 가서 스킬이 안 나가는데,
> 그래서 이 앱은 그 API를 쓰지 않고 수동적 리스닝만 합니다.

**후킹이 안 되면** 앱을 관리자 권한으로 실행해 보세요. 게임이 관리자 권한으로 돌고 있으면
일반 권한 앱에는 그 입력이 보이지 않습니다. 그래도 안 되면 후킹을 끄고 수동 모드로 쓸 수 있습니다.

### 4. 채팅 칠 때

채팅창에 "이프리트 갈게요"를 치면 그 글자들이 버프 키로 잡힐 수 있습니다.
그래서 **엔터를 치면 채팅으로 보고, 글자 키에 걸린 버프를 잠시 무시**합니다.

다만 채팅 엔터와 스킬창 **"확인"** 엔터는 keycode가 똑같아서 입력만으로는 구분할 수 없습니다.
확인 엔터 때문에 잘못 채팅으로 잡히면 알림이 조용히 멈추는 게 최악이라, 이렇게 처리합니다.

- **이동·점프처럼 채팅 중일 수 없는 입력이 오면 즉시 풀립니다.**
  확인 엔터로 잘못 들어갔어도 사냥을 재개하는 순간 저절로 복구됩니다
- Esc를 누르면 바로 풀립니다
- 그래도 안 풀리면 설정한 시간(기본 8초) 뒤 자동 해제
- 채팅으로 판정 중이면 **오버레이에 `채팅 중` 배지**가 뜹니다. 알림이 안 오는 이유가 바로 보입니다

> 💡 **`F1~F12` `PgUp` `PgDn` `Ins` `Del` `Home` `End`, 수식키 단독, Ctrl/Alt 조합에 걸어둔 버프는
> 채팅 중에도 그대로 동작합니다.** 채팅창에 글자를 남길 수 없는 키라서 애초에 무시 대상이 아닙니다.
> **자주 쓰는 버프일수록 이런 키에 배치하는 게 안전합니다.**

인벤 정리나 상점 이용처럼 오래 조작할 때는 **감지 일시정지** 앱 단축키를 쓰세요.
휴리스틱과 무관하게 확실히 멈추고, 다시 누르면 재개됩니다.

### 5. 사냥 중

- 등록한 키를 누르면 타이머가 자동으로 시작됩니다
- **시작** 버튼으로 수동 조작도 가능합니다 (후킹을 꺼도 앱은 그대로 쓸 수 있습니다)
- **소환수 리셋** — 맵/채널 이동 후, 소환수 타이머만 지웁니다
- **전체 리셋** — 사망 등으로 버프가 전부 날아갔을 때
- **음소거** — 타이머는 계속 돌고 음성만 멈춥니다. 오버레이에 `음소거` 표시가 뜹니다
- **감지 일시정지** — 버프 키 감지만 멈춥니다. 오버레이에 `감지 정지` 표시가 뜹니다

### 6. 오버레이

게임 위에 항상 떠 있고, 잠금 상태에서는 **클릭이 게임으로 통과**되어 조작을 방해하지 않습니다.

- 위치를 옮기려면 설정 탭에서 **잠금을 풀고** 오버레이를 드래그한 뒤 다시 잠그세요
- 노트북 단일 화면이라면 **컴팩트 모드**(가로 한 줄)가 게임 UI를 덜 가립니다
- 게임은 **창모드**로 하세요. 전체화면(exclusive fullscreen)에서는 오버레이가 보이지 않습니다

화면을 보고 있으면 오버레이 숫자를 잘 안 읽게 되므로, 주 알림 채널은 **음성**입니다.

### 7. 음성 고르기

설정 탭에서 Windows에 설치된 음성 중 하나를 고르고, **테스트 재생**으로 바로 들어볼 수 있습니다.
음량·속도·높낮이도 조절됩니다.

- 기본값은 **자동** — 설치된 한국어 음성 중 첫 번째를 씁니다
- 한국어 음성이 없으면 Windows **설정 → 시간 및 언어 → 음성 → 음성 추가**에서 설치하세요
- 목록에 **온라인**이라고 표시된 음성은 인터넷 연결이 필요합니다.
  이 앱은 오프라인으로 도는데 그 음성만 네트워크를 타서 사냥 중 끊길 수 있으니 피하는 게 좋습니다

## 현재 범위 (M1 + M2)

구현됨:

- 캐릭터 프로필 CRUD + 복제, 버프 CRUD, 버프 이름 자동완성
- 절대 시각 기반 타이머 (틱이 밀리거나 절전에서 복귀해도 어긋나지 않음)
- 사전 알림 / 만료 알림, 각각 사이클당 한 번만 발화
- 음성 알림(TTS) — 음성 선택 · 음량 · 속도 · 높낮이 · 테스트 재생
- 최소 간격 안의 알림 합치기 (넷 이상이면 "리버프")
- 오버레이 (리스트 / 컴팩트, 투명도·크기·위치·클릭 통과)
- 전체 리셋 / 소환수 리셋
- **전역 키 후킹** — 게임 키를 읽어 타이머 자동 시작 (키를 가로채지 않음)
- 실제 키를 눌러 등록하는 캡처 UI, 수식키 단독 배치 지원, 단축키 충돌 경고
- 캐릭터 전환 단축키, 앱 단축키(리셋 / 음소거 / 오버레이 토글 / 감지 일시정지)
- **채팅 감지** — 채팅 중 글자 키 무시, 이동 입력으로 즉시 복구, 상태 배지 표시

아직 없음:

- **트레이 아이콘** (M3) — 그래서 지금은 **설정 창을 닫으면 앱이 종료**됩니다.
  사냥 중에는 닫지 말고 최소화해 두세요.
- 만료 예정 시각이 가까운 버프를 끌어와 미리 함께 알리는 묶음 알림 (M3)
- 설정 내보내기/가져오기 (M3)

## 문제 해결

### `후킹을 시작하지 못했습니다: Cannot find module 'uiohook-napi'`

의존성이 설치되지 않았습니다. `git pull` 후 `npm install` 을 빠뜨렸을 때 납니다.

```bash
npm install
npm start
```

### 후킹은 켜졌는데 게임에서 누른 키가 안 잡힘

앱을 **관리자 권한**으로 실행해 보세요. 게임이 관리자 권한으로 돌고 있으면
일반 권한으로 실행된 앱에는 그 입력이 보이지 않습니다.

### 키를 눌렀는데 게임에서 스킬이 안 나감

이 앱 때문은 아닙니다. 앱은 키를 **읽기만** 하고 가로채지 않습니다
(`globalShortcut` 을 쓰지 않는 이유가 정확히 그것입니다).
다른 프로그램이 그 키를 잡고 있는지 확인해 보세요.

### 채팅을 안 치는데 오버레이에 `채팅 중` 이 떠 있음

스킬창 **확인** 버튼처럼 엔터를 쓰는 조작 뒤에 생길 수 있습니다.
이동하거나 점프하면 바로 풀리고, 그래도 남아 있으면 Esc 를 누르세요.
자주 겪으신다면 설정 탭에서 **채팅 자동 해제** 시간을 줄이거나
채팅 감지를 꺼도 됩니다.

### 음성이 안 나옴

설정 탭 → **테스트 재생**으로 먼저 확인하세요.
소리가 안 나면 한국어 음성이 없는 것이니 Windows
**설정 → 시간 및 언어 → 음성 → 음성 추가**에서 설치하세요.

```
%APPDATA%\maple-buff-alarm\maple-buff-alarm.json
```
